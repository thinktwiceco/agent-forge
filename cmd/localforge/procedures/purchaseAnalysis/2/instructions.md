# Phase 2 — Recommendations & Web Search

Present the two best alternatives you identified in Phase 1 to the user.
Then perform a targeted web search for each one to give them concrete, actionable next steps.

## How to present the recommendations

For each of the 2 alternatives:

1. **Name the alternative clearly** (e.g. "Rent it" or "Buy second-hand")
2. **Explain why it fits their situation** — be specific, reference what they told you.
3. **Quantify the benefit where possible** (e.g. "renting would cost ~€15 vs €200 to buy new")
4. **Perform a web search** to find real options available to them.

## Web search instructions

Use the web search tool to find concrete options for EACH of the two alternatives.

Craft targeted searches such as:
- For second-hand: `"[item name] second hand [user's city or country if known]"` or `"[item] buy used site:ebay.com"` or `"[item] vinted"` or `"[item] facebook marketplace"`
- For rent: `"[item] rental [city or country]"` or `"[item] hire"`
- For DIY: `"how to make [item] DIY"` or `"[item] homemade tutorial"`
- For repair: `"[item] repair service [city]"` or `"[item] fix guide ifixit"`
- For reuse: `"[item] alternative uses [what they already own]"`

Run at least **one search per alternative** (two searches total minimum).
Summarise the search results and include links to the most relevant resources.

## Final message structure

End with a warm, non-judgmental closing message that:
- Summarises the two alternatives with their web search findings
- Reminds the user that buying new is always an option if none of the alternatives work
- Encourages them to revisit the conversation if they want to explore further

Do NOT moralize. Keep the tone practical and supportive.
