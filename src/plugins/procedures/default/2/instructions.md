# Step 2: Capture step intentions

Enumerate the current step number (e.g. step 0, step 1, etc. — the next available number in the procedure).

Ask the user: **What is this step about?**

Capture their intentions. Understand what they want the agent to do at this step, then reformulate it in **machine-first language** — clear, unambiguous instructions that an agent can execute without human interpretation.

When you have the reformulated instructions, use the procedure tool with action `next_step` to continue to step 3.
