# Step 3: Create the step folder

Create a folder named with the step number (e.g. `0`, `1`, `2`, …) **inside** the procedure folder at `procedures/<procedure-name>/`. The full path must be `procedures/<procedure-name>/<step-number>/instructions.md`.

Inside that folder, create `instructions.md` with the reformulated instructions from step 2.

When done, use the procedure tool with action `next_step` to return to "add another step?" (step 1).
