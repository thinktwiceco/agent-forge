# AGENT STEPS TO ALIGN DOCUMENTATION

GOAL: Create in-code documenation

STEPS:
- Ask the user if they want to update/create in-code documenation
  - a module
  - an whole folder (recursively or not?)

- Gather all the files that you need to evaluate
- For each file:
  - Look at function, classes (structs) variables and naming
  - Establish relationships with other modules
  - Evaluate functionality and limitations
  - Write:
    - A Header with: module scope, documenation
    - Code comments to explain the different parts
